# Security policy

Report suspected vulnerabilities through [private vulnerability reporting](https://github.com/GabrielNichols/mekanism-rust-foundry/security/advisories/new). Include the affected commit or release, a minimal reproduction, and the likely impact. Share sanitized evidence and keep credentials, player data, and third-party game files out of reports.

The policy covers Foundry code, scripts, workflows, and preview packages. Report vulnerabilities specific to Minecraft, NeoForge, Mekanism, or Horizon to their respective maintainers. Use the public issue tracker for ordinary defects and parity mismatches.

The maintainer triages privately, coordinates a fix and any upstream disclosure, and publishes an advisory when appropriate. The current preview line receives fixes on a best-effort basis.

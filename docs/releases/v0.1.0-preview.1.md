# Parity Lab Preview 1

First installation-tested release of the Mekanism Rust Foundry laboratory tools. The phase focuses on Java characterization and contributor workflows.

## Included

- `mek-lab.exe` for dedicated reference execution, trace seal verification, observer simulation, and comparison.
- `mek-work.exe` for processing work evidence.
- A dedicated server smoke case, installation guide, lab license, Rust dependency notices, and a file manifest.

## Tested scope

Windows x64 with the MSVC target, Rust 1.95.0 for rebuilding, and PowerShell 7 for setup. The dedicated reference uses JDK 21, Minecraft 1.21.1, NeoForge 21.1.200, and Mekanism Core 10.7.19.85. Runtime artifacts are resolved privately through source setup. The smoke case exercises a barrel in the mod-loaded dedicated server. The Enrichment Chamber is the bounded machine pilot.

Extract the ZIP after checking `SHA256SUMS`. Follow `INSTALL.md` inside the archive or the repository release policy. The separately published `verification.json` records what ran, the source commit and archive SHA-256.

Java characterization, simulation, sealed expected references, and future Rust parity remain separate. Gameplay work begins after the relevant pre-port qualification gate. No optimization or port equivalence is established by this preview.

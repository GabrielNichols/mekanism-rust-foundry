# Foundry contributor handbook

This handbook is the Wiki landing page and points to versioned sources. The roadmap defines scope and acceptance. Issues record ownership and progress. Discussions host questions and proposals. Release notes record what was built and verified.

Use Discussions General for introductions, Q&A for help, Ideas for proposals, and Announcements for verified release news. Keep roadmap changes in a PR and avoid editing a second copy of the specification.

[Security reporting](../SECURITY.md) · [Security and quality operations](SECURITY-OPERATIONS.md)

[GitHub taxonomy](planning/GITHUB-TAXONOMY.md) defines how Discussions, issues, and PRs share labels and how the [Project](https://github.com/users/GabrielNichols/projects/2) tracks each item independently.

[Delivery milestones](planning/MILESTONES.md) define exit criteria and the maintainer preview command. GitHub Milestone carries the phase displayed in the Project, while Project Status tracks current work. Review closures and linked PR milestones manually.

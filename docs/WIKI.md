# Foundry Wiki index

Mekanism Rust Foundry maintains the Rust Parity Lab and its pinned Java reference. The lab characterizes behavior and validates evidence for a future native Horizon mod. The [scope qualification gates](planning/ROADMAP.md#gates-by-scope-and-proof-level) govern when that work can begin.

| I want to… | Read |
| --- | --- |
| Find a first task and reproduce the smoke case | [Onboarding](wiki/ONBOARDING.md) |
| Follow a case from the Rust runner to Java and back | [Architecture](wiki/ARCHITECTURE.md) |
| Draft a scenario or bind it to the Java reference | [Scenario authoring](wiki/SCENARIO-AUTHORING.md) |
| See which platform, ingress and evidence levels have been exercised | [Platform status](wiki/PLATFORM-STATUS.md) |
| Find a preview, verify a download or review a release candidate | [Release navigation](wiki/RELEASES.md) |
| Ask a question, claim work or find a real blocker | [Discussions and Project views](planning/CONTRIBUTOR-TRIAGE.md) |

The [planning bundle](planning/README.md) owns requirements and acceptance. The [issue map](planning/GITHUB-ROADMAP.md) connects stable work IDs to ownership and progress. [Delivery milestones](planning/MILESTONES.md) group roadmap phases, and [Project Status](https://github.com/users/GabrielNichols/projects/2/views/3) tracks the current actionable scope. The [status ledger](../STATUS.md) and [TDD evidence index](../evidence/tdd/README.md) report what has been exercised.

Keep this index and its pages in the source repository for review and historical lookup. When a maintainer updates [GitHub Wiki Home](https://github.com/GabrielNichols/mekanism-rust-foundry/wiki), link to this index using a full repository URL. Link to a tag or commit when the navigation describes a specific release. Keep detailed acceptance and evidence on their canonical pages.

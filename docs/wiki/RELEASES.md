# Release navigation

- **Install and verify.** Select a preview from [GitHub Releases](https://github.com/GabrielNichols/mekanism-rust-foundry/releases), verify its Windows x64 ZIP against the matching `SHA256SUMS`, and read `verification.json` for the tested source and scope. [Installation instructions](../releases/README.md#install-and-verify)
- **Reproduce a tagged run.** Use a checkout at the release tag and prepare Java artifacts privately for the in-game run. The preview includes the lab executables and smoke case. [Preview 1 notes](../releases/v0.1.0-preview.1.md) · [Published Preview 1](https://github.com/GabrielNichols/mekanism-rust-foundry/releases/tag/v0.1.0-preview.1)
- **Track the next preview.** Follow the [Next Release view design](../planning/CONTRIBUTOR-TRIAGE.md#project-views). A maintainer selects the exact release slice and links its evidence and exit conditions. [Delivery milestones](../planning/MILESTONES.md)
- **Review a package candidate.** Use a reviewed source commit and verify the extracted tools, hashes and source identity. Publication follows separate maintainer review and authorization. [Package verification](../releases/README.md#rebuild-and-review) · [Release controls](../SECURITY-OPERATIONS.md#alerts-and-release-controls)
